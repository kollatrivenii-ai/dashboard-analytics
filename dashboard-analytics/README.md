# Dashboard Analytics

A simple analytics dashboard built with plain HTML, CSS and JavaScript. No installation needed.

## Run
Open `index.html` in any browser.

## Files
- `index.html` - page structure
- `style.css` - design (colours and fonts are variables at the top)
- `script.js` - data, charts and interactions

## Use your own data
In `script.js`, replace `generateData()` (section 1) with data from your API.
Each day needs: date, visitors, sessions, orders, revenue, plus src, dev and pages arrays.
